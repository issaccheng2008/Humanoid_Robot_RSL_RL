# Stage 2 原地跨棍课程

所有训练和回放入口默认物理Stage 2，实体碰撞开启，碰棍即失败；不需要Stage 1准出。
六级课程（普通步长/初始脚尖到木棍近边净距离cm）：10/8、8/7、6/6、4/5、2/4、0/3。
课程默认从第0级开始；每级至少200个已结束回合，最近最多1000个本级回合纯净成功率严格超过70%时升一级。
失败、跌倒、碰棍、超时均算失败；旧级仍在运行的回合不参与新级统计。晋级不移动正在执行回合的木棍，仅在复位时更新。
最后一级直接从LEAD开始：普通步长课程参数为0，但策略第一帧收到跨棍步长0.23m和cross=1；先跨右脚，再收左脚。
不会等待虚假的普通步落地，也不发25分普通步完成奖励。最终级成功后继续在该级训练。

保持49/12接口、落地切换、20ms控制周期、50rpm/5N·m硬上限、25rpm超速惩罚、1.5/3N·m分段扭矩惩罚（两项权重-1）。
8秒回合期限和原有跨棍奖励保持。上位机部署未改，当前教师仍依赖阶段指令，蒸馏未实现。

默认提交：`sbatch hpc/train_walk_stop_cross.sh`，从SH指定model_850暖启动第0级。
新课程检查点保存infos.direct_crossing_curriculum，含级别、窗口和参数。断点续训用相同Stage 2检查点并加--resume，恢复窗口与级别。
旧检查点无课程信息，必须暖启动，不加--resume。暖启动默认重新从第0级开始；--curriculum-level 0..5可指定起点。
回放新检查点自动读取保存课程级别但禁止晋级；--curriculum-level可显式测试指定级别。旧检查点默认在第0级10/8cm冻结回放，也使用实体Stage 2及落地切换；可用--curriculum-level指定测试等级。
TensorBoard查看Task/direct_curriculum_level、clean_success_rate、episodes、walk_step_m、initial_gap_m（后四项同属direct_curriculum_前缀）。

已纠正起始普通步长为10cm。之前错误5→0课程的检查点只能暖启动（不要加--resume）；新课程默认从10/8cm开始，避免复用旧级别成功统计。
